# Bilder

Diese Verzeichnisse werden genutzt, **nachdem die Repository-Sichtbarkeit auf private umgestellt und überprüft wurde**.

- `originale/`: vom Nutzer übermittelte Originalbilder, unverändert
- `generiert/`: später erzeugte Abbildungen oder Regalübersichten

Fotos werden in `daten/fotos.csv` referenziert. Keine privaten Fotos in das öffentliche Repository hochladen.
